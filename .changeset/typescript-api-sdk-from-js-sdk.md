`@runpod/typescript-api-sdk` now releases from `runpod/js-sdk`. Releases up to 0.7.0 were published from `runpod/runpod-mcp`. The API is unchanged. The package now also ships `spec/openapi.yaml`, so consumers such as the MCP server can generate from the same spec.
