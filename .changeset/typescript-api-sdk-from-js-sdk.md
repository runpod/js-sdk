`@runpod/typescript-api-sdk` now releases from `runpod/js-sdk`. Releases up to 0.8.0 were published from `runpod/runpod-mcp`. The package now also ships `spec/openapi.yaml`, so consumers such as the MCP server can generate from the same spec. The API is the same as in 0.8.0.
